# 主线：阿渣和艾丽卡在诺维亚城谋生，攒路费前往西大陆并继续向北极推进

1. 第1章：商队抵达诺维亚城前遭机械族袭击，阿渣和艾丽卡被爆炸余波掀飞并炸晕。
2. 第2章：两人醒后进入诺维亚城，在杰哥帮助下凑齐冒险者注册费用。
3. 第3章：阿渣完成灵能检测，发现自己灵能敏感度极低；艾丽卡的灵能数值则高得离谱，两人正式注册成为冒险者。
4. 第4章：普通冒险任务太危险，两人先去矿场打工，结果挖到铀矿后辞职，随后转去杰哥负责的城墙修缮工地当力工。
5. 第5章：工地工资稳定但攒钱太慢，两人回到工会挑任务，先尝试“殴打朱顶红”翻车，随后准备去采集云露风信子。

当前进度：两人仍在诺维亚城，白天继续干活，晚上考虑更快的赚钱办法。

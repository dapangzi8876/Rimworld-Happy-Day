# 第一章摘要

阿托利斯（阿渣）被艾丽卡召唤到异世界后的第十三天，两人跟随一支前往诺维亚城的商队，在云海高原的山路上靠帮工和领取盒饭维持生活。阿渣把肉菜挑给艾丽卡，自己只吃白饭，因为商队厨师是金属怪形，肉菜偶尔会带有使人遭到寄生的异常物质。此前一名爱播报各地消息的商队大叔便在用餐时异变，给阿渣留下了不小的心理阴影。

阿渣回想起自己拦截大运失败后，被正在仓库中举行召唤仪式的艾丽卡召来。最初的异世界幻想很快被现实击碎：这里有游荡的机械族、坠落的陨石、会袭击路人的炎魔种和各种异常生物。两周下来，他除了更擅长逃跑，没有获得期待中的特殊能力，只能和艾丽卡一起为吃饭与赚钱发愁。

商队抵达诺维亚城外时，城门方向突然发生爆炸。城墙被机械族击穿并部分坍塌，守卫随后用检测灯排查人群中的金属怪形寄生者，将异变者当场斩杀。骚乱结束后，守卫要求检查正常的人暂时留在城内。面对身后的山路与破损的城墙，阿渣还是拉着艾丽卡随人群进城，两人在诺维亚城的生活由此开始。

## 章末状态

- 时间：阿渣被召唤后的第十三天。
- 地点：阿渣与艾丽卡已进入诺维亚城。
- 处境：两人没有稳定职业与收入，需要尽快解决生计问题。
- 已知目标：艾丽卡最终要前往北极附近；阿渣眼下优先考虑在诺维亚城赚钱和生活。
- 新增信息：诺维亚城刚遭机械族袭击，城内正在严格排查金属怪形寄生者，入城者暂时不得离开。
